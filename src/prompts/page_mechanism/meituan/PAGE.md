# Meituan Home Page

## Overview
Main page of meituan app. Choose correct location and address here, then navigate to the secode page.
No need to do more things here.

## Canonical Manual Path
- Current page: `meituan`.

## Structure
- The page contains a hidden drawer, which appears latter to main frame. Do not pay attention to it.
- The page header contains a address chooser.
- The page contains configured secondary entries such as `美食` and `外卖`.
- There are plenty of goods below. Just ignore them since their belonging merchant are missing.
- There may be some popups suggest location be configured, such as `开启定位`. Ignore them.
- XML may not match the visible layout; use screenshot when target position is unclear.
