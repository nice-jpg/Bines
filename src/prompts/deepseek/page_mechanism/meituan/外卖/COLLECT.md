# 采集指南：`meituan/外卖`（空输出）

## 输出契约

本页的商家 schema 与采集 schema 都不要求任何字段。对任何受支持的同页状态，固定返回空对象 `{}`。

不要提取、保留或输出地址、联系方式、商家、分类、搜索文本中的任何内容——它们都不在 schema 里。

## 页面识别（只用于判断"是否同一路由"）

- 地址形态：标题/头部 → 城市与位置控件 → 搜索框 → 定位状态行 → 已保存地址行。
- 列表形态：位置/搜索控件 → 分类与筛选控件 → 商家卡片。

这些结构只用来确认快照属于本页，**不产生任何字段**。

## 必需别名

- `"1"`：在空间上覆盖当前整个快照的根页面区域。它在地址形态与列表形态下都稳定，用来界定页面范围，不指向任何个人信息或附带文本。

提取器需要定位该锚点，但最终仍只输出 `{}`。

## 歧义与隐私

地址标签、收件人、电话、权限或错误提示、分类标签、商家卡片文本——即使视觉上完全清晰也一律忽略。全屏可点击层、图片层或稀疏的无障碍树可以与丰富文本共存，这不影响空输出。

## 何时重写

- schema 新增字段；
- 正式要求非空的商家身份；
- 需要更具体的语义锚点来界定所需信息。

届时写清新的"字段 → 区域"关系、相似物、缺失值处理方式与必需的别名；不要硬编码当前标签、节点 ID 或坐标。
