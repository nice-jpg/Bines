# 美团外卖入口（`meituan/外卖`）

## 规范路径
- 当前页面：`meituan/外卖`。
- 子页面：`meituan/外卖/美食`。

## 页面模型

本页有两种形态，先判断当前是哪一种再动手：

| 形态 | 典型自上而下结构 | 本页要做的事 |
|---|---|---|
| 地址未就绪 | 地址选择器 / 当前定位权限提示 / 搜索地址页 | 用可见控件完成地址与范围设置 |
| 地址已就绪 | 地址区 → 搜索框 → 分类入口 → 筛选控件 → 商家列表 | 只选分类，不采集 |

## 边界
- 本页没有任何需要采集的字段；商家卡片只是导航目标。
- 只在必要时处理地址相关控件；地址已就绪就不要反复设置。

## 判定与歧义
- 分类之下出现商家列表 → 地址已就绪。
- 只看到地址选择或定位权限提示 → 还需要先把地址搞定。
- 抽象区域与真实布局可能不一致；控件位置不确定时截图。
