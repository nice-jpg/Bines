# 采集指南：美团外卖 美食 — 商家列表定位

## 页面构成

美团外卖频道内的一段纵向堆叠（页面标题 `美食`），自上而下是：

1. 红色头部条带：返回控件 + 居中标题。
2. 圆角搜索框，显示"请输入商家或商品名称"。
3. 引导列表的推广卡片（只在列表头部可见）。
4. 横向分类标签行。
5. 排序/筛选控件行。
6. 快捷筛选标签行。
7. 可纵向滚动的商家列表。

两个悬浮气泡（推广气泡、`购物车` 气泡）固定在右边缘并压在列表之上，属于界面装饰。

滚动越深，固定保留的是分类标签行、排序/筛选带和商家卡片；推广卡片会滚出视野，排序控件也可能折叠消失。下面每个别名都按"任意滚动位置仍可定位"来选。

## 所需字段

本页 schema 为 `{"collect": false, "note": "list page requires no field collection"}`。

该界面只负责选择、排序、打开商家卡片，不含商品级字段。商家名称、评分、销量、配送费、距离、推广文本虽然可见，但它们描述的是**导航目标**，不是本页要求的字段。不要为本页输出商家或商品条目。

## 必需别名

| 别名 | 角色 | 定位要点 |
|---|---|---|
| `"1"` | 商家卡片列表容器 | 唯一一个"子节点是商家卡片、按自上而下列表顺序排列"的区域；也是列表的纵向滚动宿主。靠近列表头部时它以排序/筛选行作为第一个子节点，更靠下时只含卡片。 |
| `"2"` | 分类标签行 | 一排等宽标签组成的横向列表，首个标签是 `全部`，其后是 `饺子馄饨`、`汉堡薯条`、`意面披萨`、`包子粥店`、`快餐便当` 等分类名。推广卡片滚出视野后，它是搜索框下方的第一条带。 |
| `"3"` | 排序/筛选控件行 | 同一行承载 `综合排序`、`速度`、`全部筛选` 与快捷筛选标签 `15分钟`、`堂食店`、`神券商家`、`新客立减`；它是一个单独的容器，排序控件与标签都是它的子节点。 |
| `"4"` | 第一张商家卡片 | 列表顺序中 `"1"` 的第一个商家卡片；它拥有列表最上方的标题行。在很深的位置可能被视口顶部裁切，这不改变其角色。 |

## 可选别名

- `"5"`：引导列表的推广卡片——拥有 `广告` 标记、`进店` 按钮、带划线价的商品缩略图。只在列表头部可见时存在，因此非必需；可见时再分配。

## 几何与层级

- 标签行、控件行是横跨页面宽度、宽而短的横向带；商家卡片高度是它们的数倍，含左侧图片列和自页面宽度约三分之一处开始的右侧文本列。
- `"1"` 内部，商家卡片按可见顺序自上而下排列。**保留该顺序**，绝不按评分或优惠力度重排。
- 分类标签行、推广卡片、搜索框始终位于商家卡片之上；排序/筛选带夹在分类标签与卡片之间。

## 相似物与排除项

- **推广卡片 ≠ 商家卡片**：两者都显示商家名、评分、月售。推广卡片带 `广告` 标记、`进店` 行动号召和带划线价的商品缩略图；商家卡片带起送/配送行、距离值和优惠行。推广卡片永远不算 `"1"` 的商家卡片。
- **穿插的推广行**：也可能出现在 `"1"` 内、商家卡片之间；同样带 `广告` 标记，永远不满足 `"4"`。
- **分类标签行 ≠ 快捷筛选标签**：都以横排标签形式出现；分类行以 `全部` 开头、紧贴搜索框或推广卡片下方；快捷筛选属于容器 `"3"`，在排序控件下方。
- **重复文本节点**：每个标签和排序控件会把同一字符串暴露两次（可点击节点 + 文本/描述节点）。每个控件只计一次。
- **长按菜单**：`撤销`、`商家已经被置底`、`服务差`、`口味不好`、`距离太远`、`拉黑` 挂在商家卡片区域内，即使菜单没打开也存在；它们是动作，不是卡片内容。
- **悬浮气泡**：推广气泡与 `购物车` 气泡压在列表上，是界面装饰。

## 自检（改完指南或脚本后跑一遍）

1. `"1"` 的子节点里，除排序/筛选行外，每一项都能对应一张可见商家卡片。
2. `"2"` 的首个标签是 `全部`，且整行位于 `"1"` 之上。
3. `"3"` 同时包含排序控件与快捷筛选标签，且位于 `"2"` 与商家卡片之间。
4. `"4"` 是 `"1"` 的第一个商家卡片子节点，而不是推广卡片。
5. 滚动到任意位置，四个别名都仍能定位到同一角色。

## 稳定性与何时重写

滚动、改排序、改筛选都保持 `"1"`–`"4"` 的角色不变：只有 `"1"` 内的卡片会变，`"5"` 随列表头部出现或消失。

出现下列情况才重写：搜索框、推广卡片、分类标签行或排序/筛选带改变顺序或消失；分类行失去开头的 `全部`；直接包含商家卡片的区域改变形态（例如卡片被嵌套得更深）；schema 不再声明 `collect=false`。
