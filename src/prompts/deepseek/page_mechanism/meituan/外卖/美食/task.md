# 任务：遍历外卖美食商家并逐个进入

## 前置
- 确认当前是 `meituan/外卖/美食`；若地址未就绪，先按 `meituan/外卖` 的任务完成配置。

## 步骤

1. **配筛选**：`tap_in_page` 点击 `全部筛选` → 选择最匹配项 → `tap_in_page` 点击 `完成`。
2. **配排序**：`tap_in_page` 点击 `综合排序` → 选择 `距离优先`。
3. **读卡片**：只看可见商家卡片，用来选安全点击目标与判断列表进度，不要抄字段。
4. **进商家**：对每个符合条件的可见商家调用
   `navigate_to(..., next_path="meituan/外卖/美食/商家", merchant_name=<含分店的完整可见名称>)`。
5. **返回后重读**：列表可能刷新或重排。重新读取当前卡片；不要按位置或节点 ID 判断"已访问"。
6. **继续**：处理下一个符合条件的可见商家；没有就滑动列表。

## 停止条件
- 连续两次列表滑动都没有出现新商家，或出现明确的终止标记。

## 判定
- 之前访问过的商家不是禁止项：用既往访问与采集事实判断"再进一次是否有价值"。
- 头部不提供进度信息，不要试图从头部判断是否到底。

## 不要做
- 不要采集商家卡片上的任何字段。
- 不要在正常列表操作仍然可用时停下来提问。
- 不要用商家名、展示文案或相对路径替代 `next_path`。
