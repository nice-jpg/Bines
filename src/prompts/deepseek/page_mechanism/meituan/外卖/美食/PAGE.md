# 美团外卖美食商家列表（`meituan/外卖/美食`）

## 规范路径
- 当前页面：`meituan/外卖/美食`。
- 商家页：`meituan/外卖/美食/商家`。
- 上级：`meituan/外卖`。

## 页面模型

自上而下：

1. 红色头部：左上返回箭头 + 居中标题 `美食`。
2. 白色搜索框：`请输入商家或商品名称`。
3. 分类标签行：以 `全部` 开头，后接 `饺子馄饨`、`汉堡薯条` 等。
4. 排序/筛选行：`综合排序` / `速度` / `全部筛选`。
5. 快捷筛选标签：`15分钟`、`堂食店`、`神券商家`、`新客立减`。
6. 商家卡片列表（可滚动）。

地址未就绪时，这些内容之上可能先出现地址选择器、定位权限状态或搜索地址页。

商家卡片解剖：

- 左侧缩略图；右上区域是商家名称与分店；卡片右上角有 `进店` 按钮。
- 元信息行：月售、堂食店、起送/配送费、距离、分钟数、评分。
- 优惠标签；可选的商品预览缩略图。
- 右下角悬浮购物车按钮可能压住卡片内容，判断卡片边界前先滚动。

## 操作边界
- 本页只用于"把列表配置对，并逐个进入商家"，不采集任何字段。
- 同页控件（`综合排序`、`全部筛选` 及其确认）用 `tap_in_page`。
- 进入商家用 `navigate_to`，`next_path` 传 `meituan/外卖/美食/商家`，`merchant_name` 可选作提示。
- 返回用 `navigate_back(next_path="meituan/外卖")` 或列表自身的返回箭头。

## 判定与歧义
- 抽象区域在这里常常不能反映真实布局：定位卡片和筛选控件时，截图是最快的方式。
- `全部筛选` 会打开一个面板，必须点 `完成` 才生效。
- 列表在返回后会刷新或重排：卡片位置不是身份，节点 ID 也不是。

## Operation Observations
## 操作观察（美食商家列表）

- 头部几乎不携带任务信息，直接看搜索框以下的分类、筛选与卡片。
- 卡片的 `进店` 按钮是最稳的入口；点击卡片名称区域同样有效。
- 筛选动作属于同页交互，不要用 `navigate_to`。
- 悬浮购物车按钮会遮住最后一张卡片的右下部，需要看清时先滚动。
