# 采集指南：外卖美食商家菜单定位

## 页面分区

- **头部**：商家身份与配送信息。
- **标签栏**：同页的 点餐 / 评价 / 商家 等标签。
- **菜单区**：一条较窄的左侧分类栏 + 一条较宽的右侧商品列表。
- **底部**：结算栏。

别名 `"1"` 分配给**右侧商品列表容器**：不是分类栏，不是整页，不是推广轮播区，也不是结算栏。

采集区域的起点是"请适量点餐"提醒。位于其上方的头部推荐与广告一律排除。

## 锚定区域内会出现什么

提醒、横幅、分类标题、重复的可点击商品卡片。

- 商品卡片：左侧商品图 + 右侧文本列（标题、销量元信息、金额）+ 购买控件。
- 横幅与分类标题不是条目。
- 通知/联系方式说明即使样式像卡片，也不是食品商品。

## 字段规则

| 字段 | 取值规则 |
|---|---|
| `name` | 卡片上完整绘制的标题，含可见的词间空格与标点；卡片内换行的标题行要连起来。忽略库存浮层、图片角标、`独家优惠` 这类促销小标签。绝不追加销量文本，也不借用其他卡片的内容。 |
| `current_price` | 售卖价格的数字与小数形式，不含货币符号、不含促销价标签；保留可见的 `起` 后缀。 |
| `original_price` | 同一张卡片上被划掉的原价金额，不含货币符号；未显示时为空字符串。整数与小数片段可能按绘制顺序暴露，要结合几何位置和该卡片自身的金额行判断。 |
| `monthly_sales` | `月售` 之后的数字，保留可见的 `+` 之类的近似后缀，不带前缀。 |

按可见的上而下顺序返回条目。缺失的可选值为空字符串。

## 完整性与遮挡

- 标题与售卖金额必须**都**完全可读。
- 排除标题在面板上方被裁切、或被固定标题遮挡的卡片。固定标题可能是纯分类标签，也可能是带插图的促销条；即使介绍性横幅占据屏幕上部，它也可能保持固定。它相邻的图形/图片盒与其内边距定义了遮挡带。仅有公开边界的正向取值并不证明可见。
- 售卖价格字形行被底部边缘裁切 → 排除该卡片。
- 只有可选的原价行被裁切 → 保留卡片，`original_price` 留空。
- 卡片在完整标题与售卖价格之后才被裁切 → 仍可采集。
- 不要为边界行放宽完整性要求。

## 相似物与排除项

- 分类栏是导航，不是商品。
- 行内分类标题、推广内容没有"可购买标题 + 价格"的组合。
- 优惠角标（`立省`、`已含券`）、口味与配料标签、起送门槛、宣传折扣，都不是商品价格或名称。
- 商家名称、评分、距离属于独立的商家元信息，绝不是菜单条目；距离缺失时用空字符串。

## 自检

1. `"1"` 内每个被采纳的条目，都能在同一张卡片上同时找到标题与售卖金额。
2. 每个条目只来自一张卡片，没有跨卡片拼接。
3. 行为符合"可见顺序"，没有按价格或销量重排。
4. 不存在以分类标题、横幅、提醒、通知充当条目的情况。

## 稳定性与何时重写

只在结构定位或锚点关系需要修正时重写，不要因为商家、分类或商品标签变化而重写。

商品列表锚点有歧义时，先检查互补锚点（分类栏、共享菜单面板、点餐标签）并记录它们的结构关系，再更新指南。

变更标注指南会使旧指南下采集的**全部**用例失效：从当前商家重新采集带截图支撑的用例，而不是重新标注过时用例。只改脚本则保留当前指南下的所有回归用例。

安全滑动起点在右侧商品面板内部，远离分类锚点、购买控件与结算区。校验结束后，用同页点餐标签的回到顶部能力恢复页面。
