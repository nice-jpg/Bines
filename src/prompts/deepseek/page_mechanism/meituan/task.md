# 任务：从首页进入各二级页面

## 目标
按配置顺序进入二级页面，交给各页面的 `task.md` 继续。

## 步骤
1. 确认当前是 `meituan` 首页。
2. 需要时先完成位置/地址选择。
3. 定位第一个配置的二级入口（例如 `美食`、`外卖`）。
4. 目标可见且无遮挡时，用 `navigate_to` 传它的绝对规范路径（如 `meituan/外卖`）进入；不可见就先滚动或用截图定位。
5. 进入后按该页面的 `task.md` 执行；返回本页后再处理下一个入口。

## 停止条件
- 配置的二级入口全部处理完，或父任务指定的范围已覆盖。

## 不要做
- 不要在本页点击商品或商家卡片。
- 不要用展示文案或相对路径替代规范路径。
- 入口被遮挡时不要按"大致位置"点击。
