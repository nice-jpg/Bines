# 美团美食商家列表（`meituan/美食`）

## 规范路径
- 当前页面：`meituan/美食`。
- 商家页：`meituan/美食/商家`。
- 页面路径中不使用具体商家名称：商家名是采集数据，不是路径。

## 页面模型

自上而下：

1. 搜索框。
2. 服务图标宫格。
3. 商家列表（可滚动）。

商家卡片通常包含：标题 / 头像 / 图标区域、距离或位置文本、评分与评论片段、优惠标签、商品预览。
可能存在一条常驻的定位服务提醒，与可读的商家列表同时出现——它不影响列表操作。

## 操作边界
- 本页只负责"把列表配置对、逐个进入商家"，不在这里做商品级采集。
- 进入商家用 `navigate_to`，`next_path` 传 `meituan/美食/商家`，`merchant_name` 可选作提示。
- 返回后重新读取当前卡片；卡片位置不是身份。

## 采集目标
- 商家字段：商家名称、评分、距离。
- 卡片在滚动后可能移动；提取时要把同一可见卡片内的标题、评分、距离片段关联起来，不要跨卡片拼接。

## 输出结构
```json
{
  "merchants": [
    {
      "name": "",
      "rating": "",
      "distance": ""
    }
  ]
}
```

## 卡片点击逻辑
商家卡片有多个可点击区域，命中哪个区域决定了去向：

| 想做的事 | 点哪里 | 不要点 |
|---|---|---|
| 进入商家 | 图标、头像、标题 | 优惠券、配送、营销活动、商品预览、收藏、评价区域 |

后一列这些区域可能打开另一个页面，一旦偏离就要返回列表重来。
