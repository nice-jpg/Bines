# 美团美食商家页（`meituan/美食/商家`）

## 规范路径
- 当前页面：`meituan/美食/商家`。
- 上级列表：`meituan/美食`。
- 本手册适用于从该列表进入的**任意**具体商家；页面路径中永远不出现商家名称。

## 页面模型

| 区域 | 内容 | 滚动行为 |
|---|---|---|
| 上部 | 商家基本信息 | 滚动后可能隐藏 |
| 中部 | 标签标题：`团购`、`菜品`、`评价`、`更多推荐` | 通常保留 |
| 下部 | 商品区 | 主要采集区 |

商品区的两种常见形态：

1. **左分类 + 右商品**：左侧分类栏是导航，不是商品。
2. **单列纵向推荐/菜品列表**：每张可见菜品卡片本身就是一条商品记录。

商品卡片的价格有多种呈现方式：

- 独立的 `¥xx`；
- 行内文本片段，例如 `19.82元 套餐名`；
- 卡片未完全可见时暂时不显示价格。

销量可能只是卡片右侧附近的纯数字，不一定带标签。

## 采集目标

商家字段：商家名称、距离、评分、评论总数。
商品字段：商品名称、价格、销量。

商品数据可能出现在 `菜品`、`团购`、`优惠`、`推荐`、`套餐` 等与商品相关的标签页中。
名称、价格、销量可能被拆分在相邻区域；采集器用 COLLECT.md 的锚点标注和经截图确认的基线来校验 `run(view)`。

## Merchant Schema
```json
{
  "name": "",
  "distance": "",
  "rating": "",
  "review_count": ""
}
```

这份商家资料由采集器从页面顶部的初始证据保存，不由 `run.agent.py` 返回，也不计入条目提取评分。

## Collection Schema
```json
{
  "items": [
    {
      "name": "",
      "price": "",
      "sales": ""
    }
  ]
}
```
