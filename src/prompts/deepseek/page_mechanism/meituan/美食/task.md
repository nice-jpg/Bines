# 任务：遍历美食商家并逐个进入

## 前置
- 确认当前是 `meituan/美食`。
- 浏览商家之前先确认城市、地址与范围。

## 步骤

1. **读卡片**：只看可见商家卡片，用来选安全点击目标与判断列表进度，不要抄字段。
2. **进商家**：从标题/头像/图标区域进入，不要从优惠券或营销活动区域进入。
   调用 `navigate_to(..., next_path="meituan/美食/商家", merchant_name=<含分店的完整可见名称>)`。
3. **返回后重读**：列表可能刷新或重排。重新读取当前卡片；不要按位置或节点 ID 判断"已访问"。
4. **继续**：处理下一个符合条件的可见商家；没有就滑动列表。

## 停止条件
- 连续两次列表滑动都没有出现新商家，或出现明确的终止标记。

## 边界
- 该列表达到停止条件之前，不要从 `美食` 离开去 `外卖`。
- 出现常驻定位服务提醒但列表仍然可读时，继续正常列表操作。
- 之前访问过的商家不是禁止项：用既往访问与采集事实判断"再进一次是否有价值"。

## 不要做
- 不要采集商家卡片上的任何字段。
- 不要在正常列表操作仍然可用时停下来提问。
- 不要用商家名、展示文案或相对路径替代 `next_path`。
